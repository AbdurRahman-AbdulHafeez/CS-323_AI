**Lab Session 01: Implementing Simple Neural Network Using Perceptron**



* Synaptic Connections are Weights
* Activation Functions decide the firing rule; what is to be fired to the next neuron.
* \# of input nodes, # of output nodes, transfer function, and # of hidden nodes decide a network topology.
* A perceptron is a single-layer neural network.
* Perceptron consists of input values, weights \& bias, net sum, and an activation function.
* A single neuron in the neural networks as a straight line, i.e. y = m\*x + b
* y = True Output (z); m = Weight (w); x = Input Feature; b = bias (b). Thus, z = w\*x + b
